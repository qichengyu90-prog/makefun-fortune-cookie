One-line entry for [make.fun's "Fortune Cookie Wisdom for Developers" bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44): a single original line of fortune-cookie wisdom aimed at a software developer, at most 120 characters.

## How it works

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no randomness, no model calls — the same line every run.

```text
You will ship on Friday. The bug you fear is already in production, and it is named after you.
```
